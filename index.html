Tamagotchi: Virtual Pet Simulation Game

A text-based virtual pet game I first built as a class project. I've kept adding features to it on my own since then. Players name and customize a pet, then care for it by feeding it, playing with it, and letting it rest, while its stats change after every action.

  • Java
  • Python
  • OOP
  • Game state

What I built

  • Gameplay systems that track hunger, happiness, and stamina and update each stat based on what the player does
  • Pet customization (name, age)
  • Object-oriented classes for the pet, its actions, and the game logic
  • A menu-driven interface that reads player input and reports the pet's status after each action

Challenges & key learnings

The tricky part was balancing the stats. Each action needed to matter without letting one stat take over the game. Splitting the pet, its actions, and the game loop into separate classes made it much easier to add new features later without breaking existing ones.
